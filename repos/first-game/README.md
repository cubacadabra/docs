# `first-game` moved to `examples`

Spellbound Schoolyard now lives in [`cubacadabra/examples/first-game`](https://github.com/cubacadabra/examples/tree/main/first-game).
The standalone repository is retired. Clone `examples` alongside `tools` and
`rust`; hosts and CI build this source from `examples/first-game`.

Its package ID remains `first-game`, and its hosted `/games/first-game/` URL remains
unchanged. See the [examples repository entry](../examples/README.md) and
[contribution guide](../../CONTRIBUTING.md).
