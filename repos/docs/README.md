# `cubacadabra/docs`

**Owns:** the canonical hand-written cross-repository product, system,
contract, decision, quality, and navigation documentation.

**Does not own:** generated API references, executable fixtures, local build
instructions, or implementation-specific how-tos.

- Runs in: GitHub Markdown today; a dedicated docs frontend remains an option.
- Depends on: checked-in product evidence and the actual sibling repository boundaries.
- Used by: every Cubacadabra repository and contributor path.
- Read next: [documentation authority](../../reference/README.md), [repository map](../README.md), and [migration ledger](../../reference/migration-sources.md).
- Verify with: `python3 scripts/check_docs.py`, relative-link checks, and SVG rendering.
- Incomplete: publish/search presentation can move to `docs.cubacadabra.com` without moving canonical source.

Repository: [github.com/cubacadabra/docs](https://github.com/cubacadabra/docs)
