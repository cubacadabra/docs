# `third-game` moved to `examples`

Capability Probe now lives in [`cubacadabra/examples/third-game`](https://github.com/cubacadabra/examples/tree/main/third-game).
The standalone repository is retired. Clone `examples` alongside `tools` and
`rust`; hosts and CI build this source from `examples/third-game`.

Its package ID remains `third-game`, and its hosted `/games/third-game/` URL remains
unchanged. See the [examples repository entry](../examples/README.md) and
[contribution guide](../../CONTRIBUTING.md).
