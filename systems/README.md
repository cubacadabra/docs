# Systems

Systems explain the boundaries beneath the products. The shared runtime and
package format are the center; hosts, services, and creator tools attach to
those boundaries without becoming alternate sources of gameplay meaning.

- [Runtime](runtime/README.md) — simulation, Luau, renderer, session, and state.
- [Packages](packages/README.md) — source, build, package, and compatibility shape.
- [Assets](assets/README.md) — identity, safe import, Morph catalog, and editor seam.
- [Networking](networking/README.md) — current service path and protocol contract.
- [Authority](authority/README.md) — trust model and the unintegrated prototype seam.
- [Backend](backend/README.md) — storage, auth, moderation, and service boundaries.
- [Publishing](publishing/README.md) — immutable release and licensing boundaries.
- [Toolchain](toolchain/README.md) — native builder and Studio integration.
