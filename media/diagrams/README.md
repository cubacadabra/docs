# Flagship diagrams

These five graphics are stable orientation pieces. They answer one question
each and use visual objects—Cube, character, workspace, device, repository—so
the reader can understand the claim before reading every label.

- [Platform overview](platform-overview.svg) — what Cubacadabra is.
- [Creator lifecycle](creator-lifecycle.svg) — how source becomes a playable release.
- [Morph anatomy](morph-character.svg) — how character layers become MorphPack.
- [Cube package](cube-package.svg) — what travels between repositories and hosts.
- [Repository constellation](repository-constellation.svg) — who owns which boundary.

Detailed implementation sequences, state machines, protocol messages, and
rapidly changing dependency graphs belong in Mermaid beside their authoritative
Markdown page. These illustrations are not normative specifications.
